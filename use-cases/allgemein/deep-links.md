# Deep Links

## Übersicht

* **Intervall**: Täglich
* **Richtung**: Partnersystem → ERP
* **Entitäten**: _Basierend auf_ [_Stammdaten_](stammdaten.md)

## Beschreibung

Im ERP System werden an den jeweiligen Stammdaten Datensätzen Deep Links hinzugefügt welche den entsprechenden Datensatz im Partner System aufrufen.
