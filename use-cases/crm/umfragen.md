# Umfragen

## Übersicht

* **Intervall**: Täglich / Echtzeit (via Webhook)
* **Richtung**: ERP → Partnersystem
* **Entitäten**: _Diverse Stammdaten, ggf. mit erweiterten Details_

## Beschreibung

Für Umfragen relevante Details (meist Mieter und Mietvertrag bezogene) Daten werden vom ERP and das Partnersystem übermittelt, damit in diesem Umfragen an die Mieter erstellt und gesendet werden können.

Je nach ERP System werden die Daten entweder täglich übertragen oder basierend auf einem Prozess im ERP System ad-hoc in Echtzeit übertragen.
